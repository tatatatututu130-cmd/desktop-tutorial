# 桜暦 集客プラン(開業前〜開業後90日)

一人運営・自宅事務所・低予算を前提に、「初めての婚活の男性」を最優先で集める計画です。
今年中の退職・来年開業のスケジュールに合わせ、**開業前の今から積み上げられる資産づくり**を
中心に組んでいます。

---

## 0. 戦略の前提(なぜこの順番か)

- **男性会員は「相談したい」ではなく「解決したい」で動く。** 感情への共感より、
  手順・型・料金の明瞭さが刺さる。→ HPの「初めて専用の型」「明瞭料金」を広告の核にする
- 初めての婚活層は**指名検索をしない**(相談所名を知らない)。
  「婚活 何から」「彼女いない歴 30代」のような**悩み検索**で入ってくる。→ 検索対策が主戦場
- 一人運営なので、**やらないことを決める**のが最重要。下記の優先度1〜3に絞り、
  それ以外(TikTok、YouTube長尺、広告の多チャネル展開など)は当面やらない

---

## 1. 優先度1:今日からできる土台(開業前・費用ゼロ)

- [ ] **Googleビジネスプロフィール登録**(無料)
  - 「福岡 結婚相談所」のローカル検索・地図に表示される、最強の無料集客枠
  - 自宅住所は非公開にできる:「非店舗型(サービス提供地域)」で福岡市を設定
  - カテゴリ「結婚相談所」、写真・営業時間・説明文にHPと同じ言葉を使う
- [ ] **LINE公式アカウント開設**(無料)
  - 無料セッションの予約窓口。男性は電話より「友だち追加→ボタンで予約」が圧倒的に楽
  - HP・SNS・Googleビジネスのすべてから、導線はLINEの一本に集約する
- [ ] **HPの公開準備**(本リポジトリのindex.html)
  - ドメイン取得・サーバー契約。タイトルはSEO済み(福岡+初めての婚活専門)
  - 予約ボタンのリンク先を mailto からLINE公式のURLに差し替える

## 2. 優先度2:検索資産づくり(開業前から週1本、継続)

**ブログ記事(HP内)で「初めての男性の悩み検索」を取る。** 記事は消えない営業マンになる。

狙うキーワードの例(すべて「初めて男性」文脈で書く):
- 「婚活 何から始める 男」
- 「30代 彼女いない歴=年齢 婚活」
- 「結婚相談所 恋愛経験なし 男」
- 「お見合い 会話 話題 初めて」
- 「婚活 服装 男 30代」
- 「福岡 結婚相談所 初めて」

書き方のルール:
- 1記事1キーワード。タイトルは35文字前後でキーワードを先頭近くに(TMSセミナー資料の通り)
- 記事の結びは毎回「無料の気持ちの整理セッション」への誘導1行のみ。売り込まない
- 月4本×6ヶ月=24本たまれば、開業時には検索からの問い合わせ導線が動き始める

## 3. 優先度3:SNS(男性向けはショート動画とX、無理なく)

- 男性ターゲットの比重が高いため、Instagramだけに頼らない
  - **X(旧Twitter)**:ブログ記事の要点を分割投稿。「初めての婚活」の実用Tips
  - **ショート動画**(InstagramリールとYouTubeショートに同じ動画を両方投稿):
    「お見合いの入室、最初の10秒」「プロフィール写真のNG3つ」など型の実演が男性に刺さる
- 頻度の上限を先に決める:週2投稿まで。ブログ(優先度2)を削ってまでやらない

## 4. 開業時の一撃(来年・開業月)

- [ ] **開業キャンペーン**:スタートプラン入会金割引など(景品表示法上、割引の根拠と期間を明記)
- [ ] **プレスリリース**:「福岡に"初めての婚活専門"の相談所が開業」はニュースになる切り口。
      無料〜低価格の配信サービスで地元メディア・Web媒体へ
- [ ] **知人・前職ネットワークへの開業挨拶**:紹介は最も質が高い。
      「独身のご友人・部下・後輩がいたら」と一言添える
- [ ] 商工会議所・異業種交流会(福岡)への参加:士業・保険・不動産など「独身男性顧客を多く持つ人」
      とつながると紹介が生まれやすい

## 5. お金まわり

- **補助金**(引き継ぎ資料の検討事項):
  - 小規模事業者持続化補助金 → HP制作費・広告費・チラシ代が対象になり得る(公募回ごとに要確認)
  - 福岡県の創業支援・よかとこ系補助金 → 商工会議所の無料相談で最新の公募状況を確認
- 有料広告(リスティング等)は、無料セッションの成約率がわかるまで待つ。
  先に無料枠(Google・SEO・紹介)を使い切るのが少人数制の定石

## 6. KPI(数字はこれだけ見る)

| 指標 | 目標の立て方 |
|---|---|
| 無料セッション予約数/月 | 最重要。少人数制なら月3〜5件で十分回る |
| 予約の流入経路 | Google/検索記事/SNS/紹介 の内訳を毎月記録 |
| セッション→入会率 | 50%を超えたら集客を増やす、下回ったらセッション内容を改善 |
| ブログ公開本数 | 月4本(先行指標。問い合わせは3〜6ヶ月遅れて増える) |

## 7. 少人数制の見せ方(注意点)

- 「毎月の新規ご入会は◯名まで」と定員を明示すると希少性が出るが、
  **実際に定員運用していないのに書くと景品表示法(有利誤認)のリスク**。
  本当に定員を決めてから掲載する(例:同時にお預かりするのは20名まで、など)
- 「満席」「残◯名」表示も同様に、実態と一致させること

### 週間ルーティン例(退職前・可処分時間が少ない期間)

- 平日夜(30分×2回):ブログ1本を分割して執筆
- 土曜(2時間):ブログ仕上げ・公開、ショート動画1本撮影
- 日曜(30分):Googleビジネスに投稿1件、X投稿予約、KPI記録
