# 桜暦「初めての婚活専門」の売りを支えるエビデンス集

ホームページ・ブログ・SNS・広告で使える公的調査・大手調査のデータと出典の一覧です。
広告や販促物で使うときは、必ず「出典名+調査年」をセットで記載してください。

---

## 1. 「経験ゼロが標準」の裏付け(市場の大きさ)

| データ | 数値 | 出典 |
|---|---|---|
| 50歳時点で結婚したことのない男性(50歳時未婚率) | **28.3%(約4人に1人)** | 総務省「令和2年国勢調査」 |
| 50歳時点で結婚したことのない女性(同) | **17.8%(約6人に1人)** | 同上 |
| 交際相手がいない未婚男性(18〜34歳) | **72.2%** | 国立社会保障・人口問題研究所「第16回出生動向基本調査」(2021年) |
| 交際相手がいない未婚女性(同) | **64.2%** | 同上 |
| 恋人として交際中の未婚男性 | 21.1% | 同上 |

**注意**:出生動向基本調査の交際データは調査対象が18〜34歳のため、若年層向けの文脈でのみ使用。
全世代向け(ホームページのメイン掲載)には国勢調査の50歳時未婚率を使う。
「いずれ結婚するつもり81.4%」も同調査(18〜34歳対象)のため、使用時は対象年齢を併記すること。

**使い方**:「恋人がいないのは、未婚男性の7割。あなたは少数派ではなく多数派です」
→ 初めての婚活層の不安(自分だけ遅れている)を打ち消す一撃。男性訴求に特に有効。

## 2. 「それでも結婚したい人が多数派」の裏付け(需要)

| データ | 数値 | 出典 |
|---|---|---|
| 「いずれ結婚するつもり」未婚男性 | **81.4%** | 第16回出生動向基本調査(2021年) |
| 「いずれ結婚するつもり」未婚女性 | **84.3%** | 同上 |

**使い方**:1と組み合わせて「意欲はあるのに、出会いと経験がない」というギャップ=
桜暦が埋める市場、というストーリーになる。

## 3. 「動けば結ばれる」の裏付け(行動喚起)

| データ | 数値 | 出典 |
|---|---|---|
| 婚活サービス利用経験のある婚姻者のうち、サービスで結婚した割合 | **47.4%(約2人に1人)** | リクルートブライダル総研「婚活実態調査2024」 |
| 2023年の婚姻者全体のうち、婚活サービスで結婚した割合 | 15.3%(過去最高水準) | 同上 |
| 1年以内に結婚した夫婦の出会いのきっかけ「マッチングアプリ」 | 25.0%(職場と同率トップ) | 明治安田「いい夫婦の日」に関するアンケート調査(2025年) |

**使い方**:「婚活サービスはもう特別な手段ではない(4人に1人がアプリで出会う時代)」
+「利用した人の約半分が結婚している」→ CTAの背中押しに最適。

## 4. 「アプリを悪く言わない比較」の裏付け

- 明治安田調査(2025年):出会いのきっかけ1位はマッチングアプリ(3年連続)
  → アプリは事実として主要な出会いの場。桜暦の比較セクションの
  「アプリにも素晴らしい良さがある」というスタンスはデータとも整合する
- 一方、出生動向基本調査が示す「交際経験の少ない層の厚さ」が、
  自力進行が前提のアプリでは拾いきれない層=桜暦のターゲットの存在を裏付ける

## 5. 使用上の注意(景品表示法・信頼性)

- 出典と調査年を必ず併記する(数字だけの掲載はNG)
- 調査対象が違う数字を混ぜない(例:72.2%は「18〜34歳の未婚男性」であり全独身男性ではない)
- 「成婚率◯%」など自社実績のように誤認させる表現にしない(自社実績は開業後の実数のみ)
- 各調査は毎年〜数年おきに更新される。年1回、最新版が出ていないか確認する
  - 出生動向基本調査:国立社会保障・人口問題研究所(次回は第17回)
  - 婚活実態調査:リクルートブライダル総研(毎年9月頃発表)
  - いい夫婦の日アンケート:明治安田(毎年11月頃発表)
