# 結婚相談所 開業準備チェックリスト

「初めての婚活専門」結婚相談所の開業に向けた実務チェックリストです。
上から順に進めれば開業できる構成になっています。ホームページ(index.html)で
お客様に約束している内容と対応する項目には 🏠 を付けています。

---

## 1. 事業の土台を固める

- [ ] コンセプト確定:「初めての婚活専門/経験ゼロが標準/がんばらせない」 🏠(済)
- [ ] ターゲット確定:婚活未経験〜アプリを少し試した程度の初心者層(済)
- [ ] 屋号の決定(漢字2文字案は既存相談所との重複確認が必要。現在は仮称「ふう」)
- [ ] 屋号決定後、J-PlatPat(特許情報プラットフォーム)で商標の重複確認
- [ ] 同名・類似の相談所がないか検索エンジン・IBJ加盟店一覧で最終確認
- [ ] ドメイン取得(屋号決定後すぐに。.com / .jp の空きを確認)
- [ ] 屋号の商標出願を検討(任意。専門ポジションを守るなら推奨)

## 2. 法的手続き・書面の整備(最重要)

結婚相手紹介サービスは、期間2ヶ月超・金額5万円超の契約が
**特定商取引法の「特定継続的役務提供」** に該当します。違反は行政処分の対象なので、
開業前に必ず整えてください。

- [ ] 税務署へ開業届を提出(屋号を記載)
- [ ] 青色申告承認申請書の提出(節税のため開業届と同時が楽)
- [ ] **概要書面**の作成(契約前に交付が義務。サービス内容・料金・解約条件)
- [ ] **契約書面**の作成(契約時に交付が義務)
- [ ] クーリングオフ(8日間)の規定を書面に明記
- [ ] 中途解約の規定を明記(特商法の上限額に沿った清算ルール) 🏠「違約金なし」の約束と整合させる
- [ ] 成婚の定義を契約書で明確化(婚約時点か、真剣交際移行時点か等) 🏠成婚料の請求条件
- [ ] プライバシーポリシー作成(個人情報保護法対応。要配慮個人情報を扱う業種)
- [ ] ホームページに「特定商取引法に基づく表記」ページを追加 🏠
- [ ] 損害賠償・トラブル時の対応方針を利用規約に明記
- [ ] (任意)弁護士または行政書士による書面チェック

## 3. 連盟(会員ネットワーク)への加盟

個人相談所は単独では会員同士を引き合わせられません。連盟加盟が実質必須です。

- [ ] 主要連盟の比較(IBJ/TMS(全国結婚相談事業者連盟)/BIU/NNR等)
  - 比較軸:会員数・入会金と月会費・成婚料ルール・研修の充実度・地域の会員分布
- [ ] 加盟審査の申込み(面談・審査あり。開業の1〜2ヶ月前には着手)
- [ ] 加盟後の初期研修を受講(未経験開業の標準ルート)
- [ ] お見合いシステムの操作習得
- [ ] ホームページの記述と連盟ルールの整合確認 🏠
  - 独身証明書の提出義務/仮交際・真剣交際のルール/お見合いの流れ

## 4. 商品・料金の確定

- [ ] 3プランの料金確定(現在のサイト記載額はサンプル) 🏠
  - ライト 9,800円/はじめて標準 15,800円/フルサポート 24,800円(いずれも仮)
- [ ] 入会金・成婚料の確定(仮:55,000円/165,000円) 🏠
- [ ] 連盟へ支払う原価(会費・お見合い料等)を反映した粗利計算
- [ ] 休会制度の運用ルール確定(月会費0円を約束済み) 🏠
- [ ] 提携フォトスタジオの開拓(1〜2店) 🏠プロフィール写真の約束
- [ ] 決済手段の用意(銀行振込+クレジット決済。Squareや STORES 決済等)

## 5. 「初めて専用の型」を作る(サイトで約束した中身)

ホームページの SUPPORT 01〜07 の裏付けです。開業前に作り込むことで、
業界未経験でも品質を担保できます。

- [ ] 模擬お見合いの台本(入室→挨拶→会話→お開きまでの進行表) 🏠SUPPORT 01
- [ ] 会話準備シート(お相手プロフィールから話題・質問を組み立てるフォーマット) 🏠SUPPORT 02
- [ ] 服装ガイド(男女別・年代別・季節別の基準写真集/相談の受け方) 🏠SUPPORT 03
- [ ] デート手順書(誘い方の文例・店選び基準・当日の流れ・会計マナー) 🏠SUPPORT 04
- [ ] お断り代行の文例集(お見合い後/仮交際中/真剣交際中の3パターン) 🏠SUPPORT 05
- [ ] 理由のフィードバック変換ルール(お断り理由を「次に活きる形」に直す基準) 🏠SUPPORT 05
- [ ] 振り返り面談のフォーマット(月次。良かった点・変える点・翌月の作戦) 🏠SUPPORT 07
- [ ] 無料相談(60分)の進行台本(ヒアリング項目・勧誘しないクロージング) 🏠
- [ ] プロフィール文の作成テンプレート(「盛らずに伝わる」型) 🏠

- [ ] 90日:掲載許諾付きの「会員の声」第1号を獲得 🏠

### 進め方の目安(未経験開業の標準的な順序)

```
1. 屋号決定・ドメイン取得
      ↓
2. 連盟の比較・加盟申込み(審査に時間がかかるため先行)
      ↓
3. 加盟研修と並行して:法的書面の整備+「初めて専用の型」作り
      ↓
4. 料金確定 → ホームページ差し替え・公開
      ↓
5. 集客開始(無料相談の受付開始)=開業
```

※ 本チェックリストの法規関連(特定商取引法・個人情報保護法)は一般的な整理です。
書面の最終確認は専門家(弁護士・行政書士)への依頼をおすすめします。
