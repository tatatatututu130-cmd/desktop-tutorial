# 「私たちのおもてなし」社長賞 2025年下期 授賞式オープニング動画 制作キット

授賞式のオープニングで流す、受賞者7名の紹介VTR(約9分30秒)を
**会社のClipchamp(Microsoft 365 職場アカウント版)** で作るための資料一式です。

## このフォルダの中身

| ファイル | 内容 |
|---|---|
| `01_構成とタイムスケジュール.md` | 動画全体の構成案と、秒単位のキューシート(進行表) |
| `02_Clipchamp操作手順.md` | 会社版Clipchampの制限をふまえた、具体的な編集手順 |
| `03_台本テンプレート.md` | 受賞者1名分のテロップ・ナレーション台本の穴埋めテンプレート |
| `04_素材チェックリストとBGMガイド.md` | 受賞者から集める素材の一覧と、BGMの選び方・入手先 |

## 動画の全体像(ひと目でわかる版)

- **長さ**: 約9分30秒(10分以内に収まる設計)
- **構成**: オープニング(40秒) → 受賞者紹介 7名 × 各70秒(8分10秒) → エンディング(30秒)
- **画面サイズ**: 16:9(横長)/ 1080p で書き出し
- **1人あたりの流れ**: 名前タイトル(5秒) → 写真+受賞理由テロップ(40秒) → 本人コメントまたは周囲の声(20秒) → 締めカット(5秒)

## 作業の進め方(推奨スケジュール)

1. **素材collection(約1週間)** — `04_素材チェックリストとBGMガイド.md` の依頼文をそのまま受賞者に送る
2. **台本作成(1日)** — `03_台本テンプレート.md` に7名分を穴埋め
3. **編集(2〜3日)** — `02_Clipchamp操作手順.md` の順番どおりに作業
4. **試写・修正(1日)** — 関係者に見てもらい、名前・所属の誤字を必ず確認
5. **書き出し** — 1080p mp4で保存し、当日再生するPCで一度通し再生してテスト
