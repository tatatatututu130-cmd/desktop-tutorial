# 02. Clipchamp操作手順(会社アカウント版の制限に対応)

## まず知っておくこと:会社版Clipchampの制限

Microsoft 365 の**職場アカウント版Clipchamp**は、個人版と比べて次の制限があることが多いです。

- **テンプレートがほとんど使えない** → この資料は「テンプレートを一切使わず、白紙から作る」前提で書いています
- **ストック音楽・ストック映像が使えない(または少ない)** → BGMは外部のフリー音源を持ち込みます(→ `04_素材チェックリストとBGMガイド.md`)
- 保存先がOneDrive(会社)固定になっている場合がある → 素材も完成品も会社のOneDriveに置けば問題ありません

**テンプレートがなくても大丈夫です。** この動画は「背景色+文字+写真+音楽」だけで組み立てられる構成にしてあります。

## 手順0:素材をひとつのフォルダにまとめる

編集を始める前に、OneDriveに次のようなフォルダを作って全部入れておくと迷子になりません。

```
社長賞2025下期_動画素材/
├─ 01_田中さん/(写真2〜3枚、コメント動画、受賞理由テキスト)
├─ 02_佐藤さん/
│  …(7名分)
├─ BGM/(曲A〜D の音声ファイル)
└─ ロゴ/(会社ロゴ画像 PNG)
```

## 手順1:プロジェクトを作る

1. Clipchampを開き、「**新しいビデオを作成**」
2. 画面右上の縦横比が「**16:9**」になっていることを確認(なっていなければ変更)
3. プロジェクト名を「社長賞2025下期_オープニングVTR」などに変更

## 手順2:オープニング(0:00–0:50)を作る

1. 左メニュー「**録画と作成**」ではなく「**グラフィック**」または「**背景**」から**単色背景**を選び、タイムラインに置く(約8秒)
   - 会社カラーがあればその色に。カラーコード指定ができます
2. 「**メディア**」→「メディアのインポート」で**会社ロゴPNG**を追加し、背景の上のトラックに重ねる(中央配置)
3. 左メニュー「**テキスト**」→シンプルな「タイトル」を選び、次の3枚を順番に置く:
   - 1枚目(約8秒): 会社ロゴのみ
   - 2枚目(約12秒): 「私たちのおもてなし 社長賞」
   - 3枚目(約12秒): 「2025年下期 授賞式 〜受賞者のご紹介〜」
   - ブリッジ(約10秒): 「このたび7名の方が受賞されました」
4. 各カットの間に「**トランジション**」→「**クロスフェード(フェード)**」を入れる
   - **トランジションは全編クロスフェード1種類に統一**するのが、素人っぽくならない最大のコツです

## 手順3:受賞者1人分(70秒)を作る

`01_構成とタイムスケジュール.md` の「1名分の型」どおりに置いていきます。

1. **名前タイトルカード(5秒)**: 単色背景+テキスト(氏名を大きく、所属を小さく)
2. **写真1枚目(20秒)**: 写真をタイムラインに置き、長さを20秒に伸ばす
   - 写真を選択 → 右パネルの「**フェード**」ではなく「**エフェクト**」等にある「**ズーム(パン&ズーム/Ken Burns)**」をON → 「ズームイン」を選ぶ。静止画でも動きが出て見栄えが全く違います
3. **写真2枚目(20秒)**: 同様に置き、今度は「ズームアウト」(交互にすると単調になりません)
4. **受賞理由テロップ**: 「テキスト」→字幕風の「**下三分の一(Lower third)**」系を選び、写真の上のトラックに重ねる。1画面に**2行・40文字以内**が読みやすい上限です
5. **本人コメント動画(20秒)**: 動画をタイムラインに置き、左下に名前テロップ
   - コメント動画がない人は「笑顔の写真+コメント文のテロップ」で代用(全員動画がなくてもOK。ただし**動画がある人とない人が混在すると差が目立つ**ので、可能なら全員どちらかに統一)
6. **締めカット(5秒)**: 名前カードを再表示し「おめでとうございます!」

### 2人目以降を速く作るコツ

1人目が完成したら、そのカット一式(名前カード〜締め)をタイムライン上で**まとめて選択→コピー&ペースト**し、中身の写真と文字だけ差し替えると、7名分が一気に進みます。

## 手順4:エンディング(30秒)を作る

1. 単色背景の上に、7名の顔写真を小さく並べる(写真を7枚重ねて、それぞれ位置とサイズを調整。3枚+4枚の2段が収まりが良いです)
2. テキスト「受賞者の皆さん、おめでとうございます」
3. 最後は「**フェードアウト**」(黒へ)+BGMもフェードアウトで締める

## 手順5:BGMを敷いて音量を調整する

1. 「メディア」からBGMファイルをインポートし、**一番下のトラック**に置く
2. 曲の切り替え位置はキューシートどおり(オープニング=曲A、①〜③=曲B、④〜⑦=曲C、エンディング=曲D)
3. **音量の目安**:
   - BGMのみの場面: 音量 **40〜50%**
   - 本人コメント(声)が乗る場面: BGMを **10〜15%** まで下げる(BGMクリップを声の区間で分割して、その区間だけ音量を下げる)
4. 各曲の頭と終わりに「**フェードイン/フェードアウト**」を0.5〜1秒ずつ入れると、曲の切り替えが自然になります

## 手順6:書き出しと最終チェック

1. 右上「**エクスポート**」→ 画質「**1080p**」を選択(mp4で保存されます)
2. 9分半の動画の書き出しには数分〜十数分かかります
3. **最終チェックリスト**:
   - [ ] 氏名・所属・漢字の誤りゼロ(受賞者本人に画面写真を送って確認してもらうのが確実)
   - [ ] 順番が式次第の登壇順と一致しているか
   - [ ] 声の場面でBGMがうるさくないか
   - [ ] 当日再生するPC+プロジェクターで通し再生テスト

## 見た目を揃える3つのルール(これだけ守ればきれいに見えます)

1. **フォントは全編1〜2種類**(見出し用+本文用)。Clipchamp内の日本語対応フォントから選ぶ
2. **色は3色まで**(背景色/文字の白/アクセントの会社カラー)
3. **トランジションはクロスフェードのみ**。派手な回転・キューブ系は使わない
